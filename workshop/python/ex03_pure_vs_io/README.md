# ex03_pure_vs_io (Python)

**Timebox:** 10 minutos.

## Objetivo
Separar la lógica pura del I/O (prints) sin cambiar el comportamiento observable.

## Tarea
Implementa `after.py` para que `process_orders(...)` sea equivalente a `before.py` y pase el test.

## Restricciones
- No cambies `before.py` ni `test.py`.
- No agregues dependencias.
- Mantén la firma: `process_orders(orders)`.

## Cómo validar
Desde esta carpeta:
- `python test.py`

## Prompt (consulta lineal)
Desde la raíz del repo:
- `bash prompts/make_prompt.sh python/ex03_pure_vs_io`
