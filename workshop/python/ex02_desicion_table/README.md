# ex02_desicion_table (Python)

**Timebox:** 10 minutos.

## Objetivo
Convertir condicionales complejos en una estructura más mantenible (p. ej. tabla de decisión) sin cambiar el comportamiento.

## Tarea
Implementa `after.py` para que `shipping_cost(...)` sea equivalente a `before.py` y pase el test.

## Restricciones
- No cambies `before.py` ni `test.py`.
- No agregues dependencias.
- Mantén la firma: `shipping_cost(country, weight_kg, is_express, is_member)`.

## Cómo validar
Desde esta carpeta:
- `python test.py`

## Prompt (consulta lineal)
Desde la raíz del repo:
- `bash prompts/make_prompt.sh python/ex02_desicion_table`
